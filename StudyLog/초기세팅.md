Inspire Project 초기 셋팅 가이드

이 문서는 React + TypeScript + Vite 환경에서 Tailwind CSS, Path Alias(@), Shadcn UI를 설정하는 순서를 정리한 매뉴얼입니다.

1. 프로젝트 생성 (Vite)

터미널에서 프로젝트를 생성하고 해당 폴더로 이동합니다.

npm create vite@latest inspire_project
# 프롬프트 선택: React -> TypeScript

cd inspire_project
npm install


2. Tailwind CSS 설치 (Vite Plugin 방식)

Tailwind CSS 패키지와 Vite 플러그인을 설치하고 CSS에 적용합니다.

2.1 패키지 설치

npm install tailwindcss @tailwindcss/vite


2.2 CSS 적용

src/index.css 파일의 최상단에 다음 줄을 추가합니다. (기존 내용을 지우고 넣어도 됩니다.)

@import "tailwindcss";


3. Path Alias (@) 설정

@/components와 같이 경로를 깔끔하게 사용하기 위한 설정입니다.

3.1 Node 타입 정의 설치

Vite 설정 파일에서 Node.js 내장 모듈인 path를 사용하기 위해 필요합니다.

npm install -D @types/node


3.2 TypeScript 설정 (tsconfig.app.json)

주의: 최신 Vite 템플릿에서는 tsconfig.json이 아닌 **tsconfig.app.json**의 compilerOptions를 수정해야 합니다.

tsconfig.app.json 파일을 열고 baseUrl과 paths를 추가합니다.

{
  "compilerOptions": {
    "tsBuildInfoFile": "./node_modules/.tmp/tsconfig.app.tsbuildinfo",
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "skipLibCheck": true,

    /* Bundler mode */
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "isolatedModules": true,
    "moduleDetection": "force",
    "noEmit": true,
    "jsx": "react-jsx",

    /* Linting */
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true,
    "noUncheckedSideEffectImports": true,

    /* Path Alias 설정 추가 */
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": ["src"]
}


4. Vite 설정 (vite.config.ts)

Tailwind 플러그인을 등록하고, 실제 경로 별칭(Alias)이 동작하도록 설정을 변경합니다.

import path from "path"
import react from "@vitejs/plugin-react"
import tailwindcss from "@tailwindcss/vite"
import { defineConfig } from "vite"

// [https://vite.dev/config/](https://vite.dev/config/)
export default defineConfig({
  plugins: [
    react(),
    tailwindcss()
  ],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
})


5. Shadcn UI 초기화

Shadcn UI를 초기화하여 기본 컴포넌트 구조를 생성합니다.

npx shadcn@latest init


초기화 옵션 선택 (예시)

Which color would you like to use as base color? › Neutral
# 나머지 옵션은 기본값(Enter)으로 진행해도 무방합니다.
# (CSS Variables: yes / React Server Components: no)


6. 설치 확인 및 실행

모든 설정이 완료되었으면 개발 서버를 실행합니다.

npm run dev
